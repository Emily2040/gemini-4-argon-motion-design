# 一括コピー用・完全制作プロンプト (日本語)

**[English](./en.md)** · **[简体中文](./zh-CN.md)** · **[日本語](./ja.md)** · **[한국어](./ko.md)** · **[メイン README に戻る](../README.ja.md)**

```markdown
HyperFrames、GSAP 3.14、および Python 標準ライブラリによる決定論的ステレオ・シンセサイザー（`120.0 BPM`）を用いて、全 45.00 秒・フル HD（`1920×1080`・`60fps`・全 `2,700` フレーム）の全 6 幕モーショングラフィックス・ショーケース映像「Principles of Motion」を構築・検証せよ。

1. 全 6 幕のタイムライン構成（`60fps`・各幕 `7.50s` / `450` フレーム）：
   - 第 I 幕（`0.00s–7.50s`、オブシディアン暗視野 `#090A0D`）：慣性と力積 (Inertia & Impulse) — 位相空間変位プロット上で `expo.out` 弾道減衰、`elastic.out(1.1, 0.35)` スプリング減衰振動、`steps(6)` 離散量子化を同時比較。
   - 第 II 幕（`7.50s–15.00s`、オブシディアン暗視野 `#090A0D`）：視差と Z 空間 (Parallax & Z-Space) — 透視距離 `1250px` の CSS 3D ステージ内に 5 層の空間平面（`L05` `Z=-200px` / `0.68×` から `L01` `Z=+200px` / `1.42×` まで）を配置し、3 軸オイラー角ジンバルで回転。
   - 第 III 幕（`15.00s–22.50s`、オブシディアン暗視野 `#090A0D`）：動的テレメトリ (Telemetry in Motion) — 3 本のプロシージャル Catmull-Rom スプライン軌道、`±2σ` 信頼区間コリドー、`+4.82σ` ピーク異常値ロック照準、等幅数字（`tabular-nums`）KPI カウンター。
   - 第 IV 幕（`22.50s–30.00s`、アーカイブ紙明視野 `#F4F1EA`）：ベクター形態学 (Vector Morphology) — デュアルブレード・シャッターで紙面極性へ転換し、カーボンインク（`#0B0C10`）・クリムゾン（`#B01204`）・コバルト（`#0033B8`）の相反転構成主義ローターと黄金比（`1.618`）キャリパーを展開。
   - 第 V 幕（`30.00s–37.50s`、オブシディアン暗視野 `#090A0D`）：音響共鳴 (Acoustic Resonance) — `16.67ms`（`60Hz`）フレームごとに `AUDIO_DATA` の 16 バンド周波数エネルギー配列を参照し、同心倍音リングと `120.0 BPM` に同期した 3:4 リサジュー位相ロック曲線を駆動。
   - 第 VI 幕（`37.50s–45.00s`、アーカイブ紙明視野 `#F4F1EA`）：交響的統合 (Symphonic Synthesis) — 全 5 章の原理を 5 列エキシビション・グリッドとライブ・ミニビューポートに統合し、フレームカウンターが `2700 / 2700` に到達したのち `44.20s–45.00s` で黒へフェードアウト。

2. 決定論的音響合成と 6 段階自動検証ゲート：
   - Python 標準ライブラリのみで `scripts/generate_soundtrack.py` を記述し、`soundtrack.wav`（`44.1kHz`、16-bit ステレオ PCM、`45.000s`）と `audio-data.js`（`2,700` フレーム × `16` 正規化バンド）を生成せよ。
   - `index.html` 内で `Math.random()`、`Date.now()`、`requestAnimationFrame` を一切使用せず、すべてのアニメーションを HyperFrames のタイムラインクロックと GSAP トゥイーンから決定論的に駆動せよ。
   - `npx hyperframes check --strict` で Lint/Runtime エラー 0 件、レイアウト境界はみ出し 0 件、WCAG AA コントラスト 100% 適合を確認したのち、`principles-of-motion.mp4`（`1920×1080`、`60fps`、`2,700` フレーム）をレンダリングし、`scripts/run_gates.mjs` の全 6 ゲートをパスせよ。
```
